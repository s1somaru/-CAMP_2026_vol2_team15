# 🧠 メンタル記録アプリ（Mental Tracker）

## 📌 概要
本アプリは、就職活動におけるメンタルの変化を記録・可視化し、客観的に振り返ることを目的としたアプリです。

面接や説明会などのイベントごとに変動するメンタル状態を、カレンダー・グラフ・キャラクター機能を通して直感的に把握できるように設計しています。

---

## 💡 コンセプト
就職活動では、面接結果や選考状況によってメンタルが大きく変動します。

しかし、その変化を振り返る手段は少なく、経験が蓄積されにくいという課題があります。

そこで本アプリでは、出来事を単なる記録ではなく「成長のプロセス」として捉え直せる体験設計を重視しました。

特にキャラクター機能を中心に、就活の経験をポジティブに変換できる仕組みを導入しています。

---

## 🚀 主な機能

- 📅 カレンダーによるメンタル記録管理
- 📊 グラフによるメンタル変化の可視化
- ➖ 平均線による傾向分析
- 🧑‍🎤 キャラクターによる体験演出機能
- 🏢 企業・選考情報の詳細管理
- 📝 自己PR・ガクチカ・ToDoの統合管理

---

## ✨ 特徴

- 就活全体を1つのアプリで一元管理
- メンタルの変化を直感的に可視化
- キャラクターによる感情体験の強化
- スマートフォン対応のレスポンシブUI

---

## 🎯 工夫した点

- カレンダーとグラフを連動させ、日付ベースで直感的に振り返れる設計
- グラフに平均線を追加し、メンタル傾向を可視化
- キャラクター機能により、ネガティブな体験をポジティブに変換するUI設計
- 和色を用いた落ち着いたデザインで長時間利用を考慮
- 就活情報を統合管理し、実用性を重視した設計
